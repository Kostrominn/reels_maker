# Reels Maker 🎬

Инструменты, которыми я делаю рилсы из длинных интервью: от записей с двух-трёх камер до готовых вертикальных роликов с субтитрами, сверенными со звуком. Ролики выходят в Instagram [@kostromin.math](https://www.instagram.com/kostromin.math/) — интервью об олимпиадной математике и учёбе.

## Что внутри

**[`interview_reels/`](interview_reels/README.md)** — основной инструмент. Ролик описывается в `plans.json`: какая камера когда в кадре, где склейки, что написано в каждом субтитре. Остальное делает модуль:

- синхронизирует камеры по звуку, а камеры, которые писали без звука, — по движению в кадре;
- помогает понять, кто говорит: строит раскадровку ртов с обеих камер; для быстрых диалогов делает разделённый экран;
- рисует субтитры с выделенными словами, наклейки и вставки-чертежи, выравнивает громкость до −16 LUFS;
- проверяет готовый файл: склейки стоят в паузах, звук совпадает с картинкой точнее кадра, каждый субтитр виден на реальном кадре, текст субтитров сверяется с тем, что слышит whisper;
- собирает пак для публикации: обложки, подписи, страницу просмотра с кнопкой «Скопировать подпись» и отчёт о качестве.

**[`main.py`](docs/MAIN_PIPELINE.md)** — первая версия: автоматический конвейер (расшифровка → поиск интересных моментов через LLM → нарезка → переключение камер по громкости), публикация через Instagram Graph API и статистика по выложенным рилсам. Им нарезаны первые рилсы весной 2026 года.

## Быстрый старт

```bash
brew install ffmpeg                      # или apt install ffmpeg
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.interview.txt

python -m interview_reels demo /tmp/reels_demo   # синтетический проект: рендер и все проверки
open /tmp/reels_demo/out/СМОТРЕТЬ.html
```

Демо не требует ничьих записей. Две «камеры» тестовой картинки, шум вместо речи. Модуль сам замеряет по звуку, что вторая камера включилась на 0,5 с позже, собирает ролик и прогоняет все проверки.

На своём проекте:

```bash
python -m interview_reels -p путь/к/проекту check-text
python -m interview_reels -p путь/к/проекту check-cuts
python -m interview_reels -p путь/к/проекту render 05
python -m interview_reels -p путь/к/проекту all        # проверки, рендер, проверки готовых файлов, отчёт, пак
```

Как устроены проект, план ролика и весь конвейер — в [`interview_reels/README.md`](interview_reels/README.md).

## Принципы

Ролики цитируют живых людей, поэтому смысл важнее скорости. Спорное слово не попадает в субтитр: звук остаётся, подпись не пишется. Чья реплика, проверяется по губам, а если это непонятно, реплика звучит без субтитра. Склейки стоят в паузах, а не посреди мысли. Имена посторонних людей и чужие истории в ролики не попадают.

## Структура

```
interview_reels/   модуль: план → рендер → проверки → пак (python -m interview_reels)
main.py, src/      первая версия: автоматический конвейер, Instagram Graph API, статистика
scripts/, prompts/ вспомогательные скрипты и промпты для LLM
tests/             pytest
docs/              описание main.py и рабочие заметки
```
